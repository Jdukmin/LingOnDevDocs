# Version
V0.0.7

## Summary

"Added OAuth(not completed.)" — Backend V0.0.7과 마찬가지로 실제 OAuth
동작 코드보다는 **인증 데이터 계층 스캐폴딩**이 중심이다. `auth/data`,
`auth/domain`, `auth/presentation` 3-레이어 구조와 `ApiClient`가 이
버전에서 최초로 등장하며, 앱의 메인 화면 구조(`AodDisplay`,
`BootstrapScreen`)도 이 버전에서 확립된다.

## Major Changes

1. 인증 3-레이어 구조 최초 도입 — `auth/data/auth_api.dart`,
   `auth/domain/{auth_repository,llm_provider,user_model}.dart`,
   `auth/presentation/auth_controller.dart`(이 구조는 V0.0.10에서
   `modules/auth/`로 재구성됨).
2. `ApiClient`(`lib/core/network/api_client.dart`) 최초 구현 — `ResponseEnvelope<T>` 파싱.
3. `AodDisplay`, `BootstrapScreen` 화면 최초 구현 — 앱의 메인 진입
   구조(부트스트랩 → AOD 대시보드) 확정.
4. `BaseScreen` 공통 베이스 클래스 추가.
5. **Android 앱 패키지명 변경**: `com.example.lingon` → `com.letmeknow.app`
   (`android/app/build.gradle.kts`, `AndroidManifest.xml`, Kotlin 패키지
   경로) — 빌드 아이덴티티가 확정된 시점. 근거:
   `FRONTEND_VERSION_HISTORY_REPORT.md`(Frontend 저장소 루트) V0.0.7.

## Architecture Impact

- 앱의 Navigation 구조가 이 버전에서 확정됨: `BootstrapScreen` →
  `AodDisplay` → (`DevScreen`/`SidebarWidget`). 이 구조는 V0.1.0까지 변경
  없이 유지된다.
- 실제 로그인 동작(Google Sign-In ↔ Backend 교환)은 이 시점에 아직 없음 —
  Backend와 마찬가지로 "데이터 계층만 존재" 과도기.
