# Version
V0.0.7

## Summary

`frontend/docs/` 최초 스냅샷. 이미 상당 부분 구현되어 있던 Flutter AOD(Always-On
Display) 앱 — 3컬럼 태블릿 Dashboard, Clock/Weather/Calendar/Chat/Brief/Status
6개 위젯, `BaseModule`(ChangeNotifier) 상태 관리 패턴, Google Sign-In(당시
"Not completed" 상태였던 Backend와 별개로 Frontend 쪽 흐름은 이미 존재) —
를 처음으로 문서화했다.

## Major Changes

1. `frontend/docs/` 전체 구조 최초 도입(DevelopmentGuide, FeatureList,
   services/, state/, theme/, ui/, widgets/).
2. AOD 3컬럼 태블릿 레이아웃(`AodTabletLayout`) + 6개 핵심 위젯 문서화.
3. `BaseModule extends ChangeNotifier` 커스텀 상태 관리 패턴(외부 상태
   패키지 미사용) 확정.

## Architecture

- `BaseModule`(ChangeNotifier) 패턴이 이 버전에서 아키텍처 기준으로 확정 —
  Provider/Riverpod/Bloc 등 외부 상태 패키지를 도입하지 않는다는 원칙.
- Chat은 이 시점에 이미 **Backend를 거치지 않고 클라이언트가 OpenAI를 직접
  호출**하는 구조(`LlmGateway`/`OpenAiGateway`)로 문서화됨 — 이후
  [requirements/domain_icd/README.md](../../requirements/domain_icd/README.md)의
  핵심 실행 모델(User→Intent→Action→Tool)과 어긋나는 임시 구조로 지적된다
  (V0.0.14 이후).
- Calendar는 이 시점에 로컬 기기 캘린더만 표시(Backend 미연동) — 이 상태는
  V0.0.12(Backend Calendar API 추가) 이후에도 Frontend 쪽은 계속 유지된다.
