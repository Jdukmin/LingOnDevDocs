# Version
V0.0.11

## Summary

"Google Oauth Completed" — Backend V0.0.11(Session/Refresh Token 완성)에
대응해, Frontend가 401 자동 재시도 인터셉터, OAuth Redirect 콜백 화면,
사용자 정보 관리 UI(도시 선택, 프로필 편집)를 완성한다.

## Major Changes

1. `ApiClient._withRetry` — 401 발생 시 `POST /v1/auth/refresh`로 자동
   재시도하는 인터셉터 구현(이후 DevDocs `FeatureList.md`/`error_policy.md`가
   "미구현"으로 잘못 기술하게 되는 바로 그 기능).
2. `oauth_callback_screen.dart` 최초 구현 — Redirect 흐름의 콜백 처리 화면.
3. `city_selection_dialog.dart`, `user_info_dialog.dart` 최초 구현.
4. `auth_module.dart`/`auth_repository.dart` 대폭 보강(로그아웃, 세션 복원).

## Architecture Impact

- User Domain의 Session 개념이 Frontend에서도 완결됨(Backend V0.0.11과
  동시기) — 이 시점부터 로그인/세션 복원/자동 재시도/로그아웃 전체
  파이프라인이 동작.
- **주의**: 이 버전에서 구현된 401 인터셉터는 DevDocs
  `frontend/docs/FeatureList.md`("Refresh Token 자동 갱신(인터셉터) —
  예정")와 `docs/policies/error_policy.md`(401 행: "자동 재시도 인터셉터는
  아직 연결되지 않음")에 반영되지 않았다 — Frontend Schema Verification
  Report Finding D-2가 이 문서-코드 drift를 지적한다.
