# Version
V0.0.12

## Summary

"minor update for calendar" — Frontend가 처음으로 로컬 캘린더 대신
**Backend Google Calendar API**를 실제로 호출하기 시작하는 버전. Backend
V0.0.13(Calendar API 최초 구현)에 대응한다.

## Major Changes

1. `google_calendar_data_source.dart` 최초 구현 — `GET /v1/calendar/events` 호출.
2. `lib/route/lingon_calendar.dart` 최초 구현.
3. `calendar_module.dart`가 로컬 캘린더 대신 `GoogleCalendarDataSource`를
   사용하도록 전환(+110줄) — DevDocs `frontend/docs/FeatureList.md`가
   여전히 "로컬 캘린더 표시(완료)/Google 동기화(예정)"로 기술하는
   상태와의 drift가 이 버전에서 시작된다.
4. `calendar_widget.dart`에 인증 오류(`UNAUTHORIZED`) 상태 UI 추가.

## Added
