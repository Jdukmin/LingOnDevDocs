# Version
V0.0.8

## Summary

세 커밋으로 구성된 버전. `LingOnDevDocs`를 Git Submodule로 연결(Backend
V0.0.8과 동시기), 이어서 ICD에 맞춘 Route 계층(`LingonApiKeyRoute`,
`LingonSettingsRoute`, `LingonStatusRoute`, `LingonUsersRoute`)을 최초로
구현한다.

## Major Changes

1. `docs` Git Submodule 연결 — Frontend도 이 시점부터 DevDocs SSOT를 참조.
2. `BaseRoute` 확장(`lib/core/base/base_route.dart`, HTTP 기반 get/post/URI 빌더).
3. `LingonApiKeyRoute`, `LingonSettingsRoute`, `LingonStatusRoute`,
   `LingonUsersRoute` 최초 구현 — Backend V0.0.7의 API에 대응.

## Added

- `.gitmodules`, `docs`(submodule).
- `lib/route/{lingon_api_key,lingon_settings,lingon_status,lingon_users}.dart`.

## Changed

- `lib/core/base/base_route.dart`(+90줄) — Route 베이스 클래스 확장.
- `lib/core/network/api_client.dart`(+41줄).
- `CLAUDE.md`, `README.md` — Submodule 연결 반영.

## Fixed

없음.

## Architecture Impact

- Frontend Route 계층이 Backend API ICD와 1:1 대응하는 구조로 확립됨 —
  이 패턴(`Lingon<Domain>Route`)이 이후 모든 Backend 연동(Auth, Calendar,
  Weather)에 그대로 적용된다.
- 이 시점에 구현된 `LingonSettingsRoute`(PUT)와 `LingonApiKeyRoute`
  (PUT/DELETE)는 이후 V0.1.0 Frontend Schema Verification Report에서
  "정의되어 있으나 UI에서 호출하는 곳이 없는 dead code"로 재확인된다
  (아직 Settings/API Key 관리 화면이 없기 때문).
