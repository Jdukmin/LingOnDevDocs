# Version
V0.0.5

## Summary

"updated UI theme" — 디자인 시스템(spacing/typography)이 정식화되고,
`AodColors`가 대폭 확장된다(+408줄). 같은 커밋에 **AI Chat 기능의 최초
구현**(`LlmGateway` 추상 인터페이스 + `OpenAiGateway`)도 포함된다 —
커밋 메시지는 "UI 테마"만 언급하지만 실질적으로는 Chat/LLM 기능 추가가
더 큰 변경이다.

## Major Changes

1. `LlmGateway`(abstract) + `OpenAiGateway`(구현체) 최초 도입 — 클라이언트가
   OpenAI API를 직접 호출하는 구조.
2. `chat_module.dart` 대폭 확장(+180줄) — LLM 응답 생성 연동.
3. `lib/core/design/{app_spacing,app_typography}.dart` — 디자인 토큰 정식화.
4. `AodColors` 대폭 확장(Light/Dark 전체 토큰 세트).

## Added

- `lib/gateway/llm/{llm_gateway,openai_gateway}.dart`.
- `lib/core/design/{app_spacing,app_typography}.dart`.

## Changed

- `lib/core/utils/aod_colors.dart`(+408/-est) — 전체 색상 토큰 재정의.
- `lib/modules/chat_module.dart` — LLM 연동 로직 추가.

## Fixed

없음.

## Architecture Impact

- Chat 기능이 이 시점부터 **Backend를 거치지 않고 클라이언트가 OpenAI를
  직접 호출**하는 구조로 시작됨 — 이 구조는 V0.1.0 시점까지 변경되지
  않고 유지된다(DevDocs `requirements/domain_icd/README.md`의 핵심 실행
  모델(User→Intent→Action→Tool)과 어긋나는 임시 구조로 별도 문서에서 지적됨).
