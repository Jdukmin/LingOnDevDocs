# Version
V0.0.10

## Summary

"Google Oauth inserted completed locally" — Backend V0.0.9(OAuth
백엔드 구현)에 대응해, Frontend가 실제 로그인 흐름을 갖추기 시작한다.
동시에 `lib/modules/`의 모든 모듈이 도메인별 하위 폴더로 재구성된다
(`modules/auth/`, `modules/weather/` 등) — Frontend Schema Verification
Report가 이후 "실제 트리와 `DevelopmentGuide.md` 문서화된 트리가 다르다"고
지적하는 구조 변경이 이 버전에서 시작된다.

## Major Changes

1. `lib/modules/*` 전체를 평면 구조에서 도메인별 하위 폴더 구조로 재구성
   (`modules/auth/`, `modules/analytics/`, `modules/brief/`,
   `modules/calendar/`, `modules/chat/`, `modules/clock/`,
   `modules/sidebar/`, `modules/weather/`).
2. `lib/auth/` 3-레이어 구조(V0.0.7)가 `lib/modules/auth/auth_module.dart`로
   통합됨 — `auth_api.dart`/`auth_controller.dart`가 사라지고 `auth_module.dart`로 병합.
3. `lib/route/lingon_auth.dart` 최초 구현 — Backend `/v1/auth/google` 연동.
4. `AodDisplay`에 인증 상태 연동(+119줄).
5. 웹 플랫폼 전용 `web_history` 유틸(`_web_history_stub/_web`, 조건부 import) 추가 — Redirect 흐름의 웹 URL 처리용.

## Added

- `lib/route/lingon_auth.dart`.
- `lib/core/utils/{web_history,_web_history_stub,_web_history_web}.dart`.
- `lib/modules/auth/user_model.dart`(재구성 후 신규 위치).

## Changed

- `lib/modules/*` 전체 디렉터리 재구성(모듈당 하위 폴더).
- `lib/screen/aod_display.dart` — 인증 상태 연동.
- `lib/widget/sidebar_widget.dart` — 로그인 UI 연동 확장.
