# Version
V0.0.17

## Summary

"functional update for first launch" — Backend V0.0.17의 P0 Calendar
계약 수정에 대응하는 Frontend 측 픽스. `FRONTEND_VERIFICATION_REPORT.md`
(이 저장소 최초의 정식 검증 보고서, 이 커밋에 포함)가 Backend
Verification Report를 근거로 Calendar 응답 필드 파싱을 정정한다. 같은
날짜의 "local difference update" 커밋도 이 버전에 포함한다.

## Major Changes

1. **[P0]** `CalendarEvent.fromJson`이 `summary`/`start`/`end`를 읽도록
   수정(기존 `title`/`startTime`/`endTime`에서 변경) — Backend V0.0.17의
   필드명 정정과 짝을 이루는 수정.
2. **[P0]** `LingonCalendarRoute.getEvents()`가 더 이상 `from`/`to`/`limit`
   쿼리 파라미터를 보내지 않도록 단순화(무인자 호출).
3. 내부 Dart 모델 필드명(`CalendarEvent.title/start/end`)은 유지 —
   JSON *파싱 키*만 변경(Domain ICD의 정규화 원칙을 그대로 따름).

## Added

- `FRONTEND_VERIFICATION_REPORT.md`(193줄) — 최초 정식 검증 보고서.

## Changed

- `lib/modules/calendar/calendar_module.dart` — `fromJson` 파싱 키 변경.
- `lib/route/lingon_calendar.dart` — 쿼리 파라미터 제거, 시그니처 무인자화.
- `lib/modules/calendar/google_calendar_data_source.dart` — 호출부 갱신(`_route.getEvents()`).

## Fixed

- Calendar 응답 필드명 SSOT 불일치(P0, Backend V0.0.17과 짝).
- 코드 주석의 오기(`from`/`to` 폴백이 실제로 없었는데 있다고 서술하던 주석) 정정.

## Architecture Impact

- `requirements/domain_icd/calendar.md`의 정규화 테이블(Backend
  `summary`→Domain `title` 등)이 이 버전부터 코드가 실제로 구현하는
  상태와 일치하게 됨 — 이전에는 코드 주석만 이 매핑을 주장하고 실제
  구현은 다른 키를 읽고 있었다.
