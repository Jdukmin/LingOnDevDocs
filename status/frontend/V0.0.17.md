# Version
V0.0.17

## Summary

"functional update for first launch" — Backend V0.0.17의 P0 Calendar
계약 수정에 대응하는 Frontend 측 픽스. `FRONTEND_VERIFICATION_REPORT.md`
(이 저장소 최초의 정식 검증 보고서, 이 커밋에 포함)가 Backend
Verification Report를 근거로 Calendar 응답 필드 파싱을 정정한다. 같은
날짜의 "local difference update"(`6f7dc7e`) 커밋도 이 버전에 포함하며,
**이 커밋이 정확히 `GoogleCalendarDataSource._codeToMessage`(62줄) —
이 코드베이스에서 유일하게 올바른 `error.code`→사용자 메시지 매핑
참조 구현 — 을 도입한 지점**이다(근거:
`FRONTEND_VERSION_HISTORY_REPORT.md` V0.0.16, Frontend 저장소 루트).
Weather의 P0 결함(에러 메시지 미매핑, [current_status.md](../current_status.md) 참고)을
수정할 때 이 커밋의 패턴을 그대로 재사용해야 한다.

## Major Changes

1. **[P0]** `CalendarEvent.fromJson`이 `summary`/`start`/`end`를 읽도록
   수정(기존 `title`/`startTime`/`endTime`에서 변경) — Backend V0.0.17의
   필드명 정정과 짝을 이루는 수정.
2. **[P0]** `LingonCalendarRoute.getEvents()`가 더 이상 `from`/`to`/`limit`
   쿼리 파라미터를 보내지 않도록 단순화(무인자 호출).
3. 내부 Dart 모델 필드명(`CalendarEvent.title/start/end`)은 유지 —
   JSON *파싱 키*만 변경(Domain ICD의 정규화 원칙을 그대로 따름).
4. `GoogleCalendarDataSource._codeToMessage` 도입(`6f7dc7e`) —
   `CalendarErrorException`/`CalendarNotConnectedException`에 정책 준수
   `toString()` 메시지 부여. `ApiClient`의 429-retry/401-refresh 로직도
   함께 다듬어짐(28줄).

## Added

- `FRONTEND_VERIFICATION_REPORT.md`(193줄) — 최초 정식 검증 보고서.
- `GoogleCalendarDataSource._codeToMessage`(`6f7dc7e`) — 에러 코드→한국어
  메시지 매핑 최초 구현(Weather가 아직 갖지 못한 패턴).

## Changed

- `lib/modules/calendar/calendar_module.dart` — `fromJson` 파싱 키 변경(+ 일일 단위 분할 로드 패턴, `6f7dc7e`).
- `lib/route/lingon_calendar.dart` — 쿼리 파라미터 제거, 시그니처 무인자화.
- `lib/modules/calendar/google_calendar_data_source.dart` — 호출부 갱신(`_route.getEvents()`) + 에러 매핑 추가.
- `lib/core/network/api_client.dart` — retry 래퍼 정교화(28줄, `6f7dc7e`).
- `lib/modules/brief/brief_module.dart` — 소규모 연동(`6f7dc7e`).

## Fixed

- Calendar 응답 필드명 SSOT 불일치(P0, Backend V0.0.17과 짝).
- 코드 주석의 오기(`from`/`to` 폴백이 실제로 없었는데 있다고 서술하던 주석) 정정.

## Architecture Impact

- `requirements/domain_icd/calendar.md`의 정규화 테이블(Backend
  `summary`→Domain `title` 등)이 이 버전부터 코드가 실제로 구현하는
  상태와 일치하게 됨 — 이전에는 코드 주석만 이 매핑을 주장하고 실제
  구현은 다른 키를 읽고 있었다.
