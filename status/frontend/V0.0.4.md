# Version
V0.0.4

## Summary

Frontend 프로젝트의 실질적 시작점("Foundation"). Flutter 프로젝트 스캐폴드
(Android/iOS/Web/Windows/Linux/macOS 타겟)부터 시작해, `BaseModule`/`BaseRoute`/
`BaseWidget`/`BaseLayout` 공통 베이스 클래스 패턴, 첫 기능(Weather), AOD
3컬럼 태블릿 레이아웃과 6개 핵심 위젯(Clock/Weather/Calendar/Brief/Chat/
Sidebar/Status)까지 이 버전에서 모두 확립된다. 8개 커밋에 걸친 급격한
초기 개발 구간을 하나의 버전으로 묶었다.

## Major Changes

1. Flutter 멀티플랫폼 프로젝트 스캐폴드(Android/iOS/Web/Windows/Linux/macOS).
2. `BaseModule extends ChangeNotifier` 상태 관리 패턴 확립 — 외부 상태
   패키지(Provider/Riverpod/Bloc) 미사용 원칙이 이 시점부터 유지됨.
3. AOD(Always-On Display) 3컬럼 태블릿 레이아웃(`aod_tablet_layout.dart`) 확정.
4. 6개 핵심 위젯(Clock/Weather*/Calendar/Brief/Chat/Sidebar/Status) 최초 구현.
5. `ICD.md`(루트, v2.0) 최초 작성 — 이후 DevDocs SSOT와는 별개로 유지되다가
   V0.1.0 시점에 "orphaned doc" 문제로 지적됨.

- Flutter 프로젝트 전체 스캐폴드(`android/`, `ios/`, `web/`, `windows/`, `linux/`, `macos/`).
