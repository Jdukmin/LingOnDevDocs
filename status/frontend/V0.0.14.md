# Version
V0.0.14

## Summary

이 버전의 핵심 작업(Personal Action OS 전략 전환, Domain ICD/Requirements
최초 도입)은 `docs/`, `requirements/`에 집중되어 있다([backend/V0.0.14](../backend/V0.0.14.md)
Summary와 동일한 맥락). `frontend/docs/` 자체의 변경은 4개 파일에 대한
소규모 배너 추가뿐이다 — 향후 Action Layer 도입이 각 문서에 미칠 영향을
미리 알리는 주석 성격.

## Major Changes

1. `frontend/docs/services/LlmService.md`에 **Deprecated(대체 예정)** 배너
   추가 — 클라이언트가 OpenAI를 직접 호출하는 현재 구조가 향후
   `POST /v1/actions/execute {type: "llm.chat_complete"}` 경유로 대체될
   예정임을 명시(코드 변경은 아직 없음).
2. `frontend/docs/ui/AodDisplay.md`에 화면 흐름 재검토 배너 추가 — Dashboard가
   앱의 유일한 메인 화면인 현재 구조가 "Dashboard는 항상 마지막 화면"이라는
   새 전략과 어긋난다는 점을 명시(위젯/레이아웃 자체는 변경 없음).
3. `frontend/docs/state/Overview.md`에 향후 `ActionModule`/`ActionHistoryModule`/
   `SuggestionModule` 추가 예정 배너.

## Added

없음(신규 파일 없음 — 기존 4개 파일에 배너만 추가).

## Architecture

- 이 버전 자체는 Frontend 아키텍처를 변경하지 않는다 — 모든 배너가 "지금
  당장 코드/구조를 바꾸지 않는다"는 점을 명시적으로 강조한다.
- 다만 이 버전에서 확정된 [docs/icd/frontend_interaction_flow.md](../../docs/icd/frontend_interaction_flow.md)
  (Chat → Intent Parsing → Action Result → History → Dashboard 제안)는
  이후 Frontend가 언젠가 따라야 할 목표 아키텍처로 문서화됨 — 아직 구현은
  시작되지 않았다.
