# Version
V0.1.0 — Baseline Release

## Summary

**V_0.1.0 Baseline.** V0.0.17의 기능 수정 이후, 두 번째 독립적인 읽기
전용 감사(`FRONTEND_SCHEMA_VERIFICATION_REPORT.md`, 2026-07-23 작성 —
정적 코드 분석 기반, Flutter SDK 미설치 환경이라 `flutter analyze`/`test`/`build`는
미실행으로 정직하게 보고됨)의 결과를 반영해, 이 시점의 Frontend 상태를
프로젝트의 첫 공식 베이스라인으로 승격한다. 코드 변경은 없다.

## Major Changes

1. Frontend Schema Verification Report 완료 — Backend Contract
   Compatibility 7개 도메인 전수 대조, DevDocs Compliance 6건 drift 발견.
2. **[P0, 신규 발견]** `WeatherModule`에 `error.code`→사용자 메시지 매핑이
   없음 — 날씨 API 실패 시 `RouteException.toString()` raw 디버그
   문자열이 그대로 사용자에게 노출됨(`docs/policies/error_policy.md`
   위반). Calendar/Auth는 이미 매핑을 구현했으나 Weather만 누락.
3. DevDocs 6건 drift 확인(D-1~D-6) — Calendar/401 인터셉터는 코드가
   문서보다 앞서 있고(문서가 오래됨), 루트 `ICD.md`는 SSOT와 충돌하는
   오래된 Weather 스키마를 여전히 보유.
4. `verification/backend/`가 이 시점까지 비어 있었다는 사실을 이 보고서가
   지적(D-6) — DevDocs 저장소가 이후 "architecture modifications" 커밋에서
   `verification/`/`version/`/`changelog/` 체계를 도입하는 계기가 됨.
