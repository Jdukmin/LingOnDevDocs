# Version
V0.0.9

## Summary

Google OAuth 인증을 최초로 도입한 버전이다("minor update for Oauth"). V0.0.7
시점에 "Not completed"였던 인증이 이 버전에서 ID Token 흐름 + Redirect
흐름 두 가지로 완전히 구현되고, 전역 JWT 인증 미들웨어(`Policy.before()`)가
처음으로 실제 동작한다.

## Major Changes

1. Google OAuth2 로그인 2가지 흐름(ID Token, Authorization Code Redirect) 최초 구현.
2. 전역 `preHandler` 훅(`Policy.before()`)이 JWT 검증 + `req.ctx.userId` 채우기를
   실제로 수행하기 시작 — V0.0.7 시점의 "인증 미구현으로 인한 401 무조건 발생"
   문제가 해소됨.
3. `users` 테이블에 `provider`/`provider_id`/`nickname`/`profile_image` 컬럼 확정
   (이전 버전의 `name`/`avatar_url` 추정 컬럼명을 대체).

## Added

- `backend/docs/api/auth.md` — `/v1/auth/*` 최초 문서화: `POST /v1/auth/google`(ID Token),
  `GET /v1/auth/google` + `/callback`(Redirect), JWT payload, Google→DB 필드 매핑, Security invariants.
- `backend/docs/plugins/google-oauth.md` — `GoogleOAuth` 플러그인(`@fastify/oauth2`
  조건부 등록, 활성화 조건 3개 env var).
- `backend/docs/services/google-auth.md` — `GoogleAuthAPI`(ID Token 검증, `google-auth-library`).

## Changed

- `backend/docs/database/users.md` — 컬럼 재정의(`name`→`nickname`, `avatar_url`→`profile_image`),
  `UNIQUE (provider, provider_id)` 제약 명시, `upsertByProvider` 원자적 upsert 쿼리 추가.
- `backend/docs/plugins/policy.md` — `before()` 훅을 "no-op(ICD v0.0: Auth None)"에서
  실제 JWT 검증 로직으로 갱신.
- `backend/docs/services/README.md` — 게이트웨이 목록에 `GoogleAuthAPI` 추가.
- `backend/docs/FeatureList.md` — "OAuth login — Not completed" 항목 제거,
  "Google login" 2건 + "JWT authentication middleware"를 Current(implemented)로 이동.
  Planned 절의 "Authentication middleware wiring"을 "Token refresh endpoint"로 교체
  (인증 자체는 완료됐으나 refresh 교환 엔드포인트는 아직 없음을 명시).

## Fixed

- `backend/docs/api/users.md` — "`GET`/`PATCH /v1/users/me`가 `req.ctx.userId` 미설정으로
  도달 불가능"하다던 이전 버전의 기술을 "정상 동작"으로 정정(인증 구현 완료에 따른 결과).

## Architecture

- User Domain의 인증/세션 부분이 이 버전에서 최초로 실제 아키텍처를 갖춤 —
  이후 모든 버전(User Domain, CON-006 OAuth Management)의 기반이 된다.
- ICD v0.0 envelope, DB 스키마(users 테이블) 등 기존 아키텍처는 변경 없음
  (컬럼명 정정만 있었을 뿐 스키마 구조는 유지).
