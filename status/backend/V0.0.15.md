# Version
V0.0.15

## Summary

"Calendar Function Completed" — V0.0.13에서 도입된 Calendar 연동을
실사용 가능한 수준으로 다듬는다. `GoogleCalendarAPI`/`googleTokenRepository`/
`LingOnCalendar.ts`가 모두 보강되며, 이 시점에 문서화되지 않은 `from`/`to`/`limit`
쿼리 파라미터가 코드에 추가된다(이후 V0.0.17에서 SSOT 불일치로 지적되어
제거됨).

## Major Changes

1. `GoogleCalendarAPI.ts` 응답 정규화 로직 보강.
2. `googleTokenRepository.ts` 토큰 갱신 로직 보강(만료 임박 판단 등).
3. `LingOnCalendar.ts`에 `from`/`to`/`limit` 쿼리 파라미터 추가(문서화되지
   않은 커스터마이징 — 이후 V0.0.17에서 제거됨).

## Added

없음(기존 파일 확장).

## Changed

- `src/gateway/GoogleCalendarAPI.ts`, `src/db/googleTokenRepository.ts`,
  `src/route/LingOnCalendar.ts` — Calendar 조회 로직 전반 보강.
- `src/app.ts` — 소규모 연동 조정.

## Fixed

없음(이 버전이 도입한 `from`/`to`/`limit`는 오히려 다음 버전에서 "수정
대상"으로 지적됨 — 아래 Architecture Impact 참고).

## Architecture Impact

- 이 버전에서 추가된 `from`/`to`/`limit` 쿼리 파라미터는
  `backend/docs/api/calendar.md`(Request 절)와
  `backend/docs/services/google-calendar.md`(Input 절: `{userId: string}`만
  정의)에 문서화되지 않은 확장이었다 — Backend Verification Report(V0.0.17)가
  이를 "real bug"로 지적하고 제거한다.
