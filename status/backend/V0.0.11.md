# Version
V0.0.11

## Summary

"Google Oauth Completed" — Session 생명주기(현재 사용자 조회, Refresh
Token rotation, 로그아웃)가 완성되어 인증 기능 전체가 마무리된다.
`refresh_tokens` 테이블과 `LingOnSession.ts` 라우트가 이 버전의 핵심이다.

## Major Changes

1. `refresh_tokens` 테이블 최초 마이그레이션(`002_users_city_and_refresh_tokens.sql`) —
   SHA-256 해시 저장, rotation 지원 컬럼, `users.city` 컬럼도 함께 추가.
2. `LingOnSession.ts` 최초 구현 — `GET /v1/auth/me`, `POST /v1/auth/refresh`,
   `POST /v1/auth/logout`.
3. `refreshTokenRepository.ts` — rotation/revoke 쿼리 구현.
4. `Jwt.ts`에 `tokenVersion` 기반 rotation 검증 추가.

## Added

- `src/db/refreshTokenRepository.ts`.
- `src/route/LingOnSession.ts`.

- `src/plugins/LingOnOAuth/GoogleOAuth.ts` — 소규모 조정.
