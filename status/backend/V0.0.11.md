# Version
V0.0.11

## Summary

로그인 UI를 지원하기 위해 세션 관리 기능(현재 사용자 조회, Refresh Token
교환, 로그아웃)을 완성한 버전이다("minor update for login ui"). V0.0.9에서
로그인만 가능했던 상태에서, 이 버전부터 로그인 이후의 전체 세션 생명주기가
Backend에서 완결된다.

## Major Changes

1. `GET /v1/auth/me`, `POST /v1/auth/refresh`(rotation), `POST /v1/auth/logout` 최초 구현.
2. `refresh_tokens` 테이블 도입 — SHA-256 해시 저장, rotation, idempotent revoke.
3. Redirect 로그인 흐름에 플랫폼 감지(web/android)와 URL fragment 토큰 전달 도입(보안 강화).
4. `users.city` 컬럼 추가(`PATCH /v1/users/me`로 사용자가 직접 설정).

## Added

- `backend/docs/database/refresh_tokens.md` — 신규 테이블 전체 문서화
  (컬럼, 인덱스 3종, Security rules, Cleanup 미구현 명시).
- `GET /v1/auth/me`, `POST /v1/auth/refresh`, `POST /v1/auth/logout` — `backend/docs/api/auth.md`에 추가.

## Changed

- `backend/docs/api/auth.md` — Redirect 흐름에 플랫폼 감지 순서
  (`x_auth_platform` 쿠키 → `X-Platform` 헤더 → `User-Agent` → 기본값 `web`)
  추가, 토큰 전달을 query string에서 URL **fragment**(`#`)로 변경(서버/프록시
  로그 노출 방지), JWT payload에 `tokenVersion` 필드 추가(rotation 지원).
- `backend/docs/database/users.md` — `city` 컬럼 추가.
- `backend/docs/api/users.md` — `PATCH /v1/users/me`에 `city` 필드 지원 추가.
- `backend/docs/routes/README.md`, `backend/docs/FeatureList.md` — 신규 라우트
  (`LingOnSession.ts`: `/v1/auth/me`, `/refresh`, `/logout`) 반영.

## Fixed

없음(이 버전은 신규 기능 추가가 중심 — 기존 문구 정정은 없었음).

## Architecture

- User Domain의 Session 개념이 이 버전에서 완결됨 — `Session`(로그인 상태)이
  액세스/리프레시 토큰 rotation으로 실제 표현됨
  ([requirements/domain_icd/user.md](../../requirements/domain_icd/user.md) — 사후 정의).
- Refresh Token 저장 정책(SHA-256 해시만 저장, 평문 미저장)이 이 버전에서
  확정되어, 이후 `docs/policies/security_policy.md`(V0.0.16)의 정책 근거가 된다.
