# Version
V0.0.7

## Summary

이 저장소(`LingOnDevDocs`)의 Backend 문서화 역사상 **최초의 실질적 스냅샷**이다.
이미 상당 부분 구현되어 있던 Fastify 백엔드(Weather 프록시, BYOK API Key,
Settings, User 프로필, 요청/서버 로깅, Rate Limit, ICD v0.0 공통 응답 envelope)의
구현 상태를 처음으로 문서화했다. 같은 커밋에 문서 검색 포털(정적 사이트)도
함께 도입됐다.

## Major Changes

1. `backend/docs/` 전체 구조 최초 도입(DevelopmentGuide, FeatureList, api/,
   database/, deployment/, plugins/, routes/, services/).
2. 저장소 루트에 문서 포털(정적 사이트: `index.html`, `assets/app.js`,
   `assets/style.css`, `assets/manifest.json`, Mermaid 렌더링) 도입.
3. Weather API(OpenWeather 프록시), BYOK API Key 저장, Settings(AI/UI),
   User 프로필, Health Check 등 이미 구현되어 있던 기능 전체를 문서화.

## Added

- `backend/docs/DevelopmentGuide.md` — Fastify 구조, Route/Plugin/Service/Repository/DTO 규칙, Error Handling, Logging, Validation 컨벤션.
- `backend/docs/FeatureList.md` — Backend 구현 상태 단일 출처(Current/In progress/Planned/Deprecated/TODO).
- `backend/docs/api/{status,weather,settings,apikey,users}.md` — 5개 API 그룹 최초 문서화.
- `backend/docs/database/{README,users,ai_settings,ui_settings,request_logs,raw_logs,user_api_keys}.md` — DB 구현 상태 스냅샷(마이그레이션 파일 없음, 코드에서 역추론임을 명시).
- `backend/docs/plugins/{README,config-handler,policy,repositories,request-context,request-log}.md` — Fastify 플러그인 5종 + 목록.
- `backend/docs/routes/README.md` — 라우트 등록 메커니즘(`@fastify/autoload`, `/v1` prefix).
- `backend/docs/services/{README,openweather}.md` — `BaseGateway` 패턴 + OpenWeather 게이트웨이(당시 유일한 concrete gateway).
- `backend/docs/deployment/README.md` — 빌드/실행/환경변수/로그 위치.
- 문서 포털(`index.html`, `assets/*`, `scripts/build-manifest.js`, `serve.js`) — Backend/Frontend 문서를 브라우저에서 검색.

## Architecture

- ICD v0.0 공통 응답 envelope(`{success, data, error}`)가 이 시점에 이미
  전역 적용된 상태로 문서화됨(`AppError.plugin`).
- 인증은 이 시점에 **아직 구현되지 않음** — `backend/docs/FeatureList.md`가
  "OAuth login — Not completed"라고 명시했고, `req.ctx.userId`가 항상
  `undefined`라 인증이 필요한 라우트(`/v1/users/me`, `/v1/settings/*`,
  `/v1/apikey/*`)는 전부 401을 반환하는 상태였다(다음 버전 V0.0.9에서 해소).
