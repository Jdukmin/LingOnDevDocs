# Version
V0.1.0 — Baseline Release

## Summary

**V_0.1.0 Baseline.** V0.0.17의 기능 수정 이후 진행된 두 번째, 독립적인
**읽기 전용 감사**(`BACKEND_SCHEMA_VERIFICATION_REPORT.md`, 2026-07-23
작성 — 실제 서버/Postgres 16/curl로 19개 문서화 엔드포인트 전체를 실행
검증)의 결과를 반영해, 이 시점의 Backend 상태를 프로젝트의 첫 공식
베이스라인으로 승격한다. 코드 변경은 없다 — 이 버전은 "감사를 통과한
상태"를 공식 기준점으로 선언하는 것이다.

## Major Changes

1. Backend Schema Verification Report 완료 — 19개 문서화 API 전부 실제
   실행 검증, DB 스키마/보안/CORS/HTTPS 감사.
2. **[High]** DB 마이그레이션 커버리지 부족 발견 — 7개 테이블 중 5개
   (`users` 기본 테이블, `ai_settings`, `ui_settings`, `user_api_keys`,
   `request_logs`, `raw_logs`)가 `CREATE TABLE` 마이그레이션 파일이 없어
   `migrations/`만으로 스키마를 재현할 수 없음(Recommended Fix만 제시,
   미적용).
3. **[Medium]** CORS가 `origin: true`로 완전 개방 상태임을 확인(모든
   Origin 반사) — 프로덕션 전 명시적 allow-list 필요.
4. **[Medium]** HTTPS/HSTS가 코드 레벨에서 전혀 강제되지 않음을 확인 —
   전적으로 문서화되지 않은 리버스 프록시에 의존.
5. `CLAUDE.md`가 대폭 갱신되어(147줄) 이 저장소의 Claude 실행 규칙이
   확정됨, `docs` submodule이 DevDocs의 SSOT 정리 완료 커밋을 가리키도록 갱신.
