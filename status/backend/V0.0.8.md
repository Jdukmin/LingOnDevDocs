# Version
V0.0.8

## Summary

두 커밋으로 구성된 버전. 첫 번째("Added Submodule docs")는 `LingOnDevDocs`를
Git Submodule로 연결해 이 저장소가 처음으로 DevDocs SSOT를 참조하기
시작한 지점이다. 두 번째("Updated Routings to match ICD")는 `Jwt.ts`
유틸리티와 `LingOnAuth.ts` 라우트의 최초 골격을 추가한다 — 실제 로그인
로직은 다음 버전(V0.0.9)에서 완성된다.

## Major Changes

1. `docs` Git Submodule 연결 — 이후 모든 버전이 `backend/docs/*.md`를 SSOT로 참조.
2. JWT 유틸리티(`Jwt.ts`) 최초 구현 — HMAC-SHA256 서명/검증 함수.
3. `LingOnAuth.ts` 라우트 골격 추가, `Policy.ts` preHandler가 인증 검증
   로직을 갖기 시작.

## Added

- `.gitmodules`, `docs`(submodule) — DevDocs 연결.
- `src/core/utils/Jwt.ts`.
- `src/route/LingOnAuth.ts`(골격).

## Changed

- `src/plugins/LingOnDataManage/Policy.ts` — no-op였던 `before()`가 Bearer
  토큰 검증 로직을 갖기 시작.
- `CLAUDE.md`, `README.md` — Submodule 연결에 따른 문서 갱신.

## Fixed

없음.

## Architecture Impact

- 이 버전부터 Backend가 `LingOnDevDocs`(SSOT)를 명시적으로 참조하는
  구조가 확립됨 — 이후 모든 API/Domain 계약 변경은 이 Submodule을 통해
  전달된다(현재 이 저장소의 `CLAUDE.md` "ICD Rule"과 동일한 원칙의 시초).
