# Version
V0.0.4

## Summary

Backend 프로젝트의 실질적 시작점("Foundation"). Fastify 앱 스캐폴드,
`BaseGateway`/`BaseProvider`/`BaseRoutes`/`BasePolicy` 공통 베이스 클래스
패턴, 첫 번째 실제 게이트웨이(OpenWeather), ICD v0.0 에러 처리(`AppError`),
구조화 로깅(Pino 기반 `Logger.ts`), Postgres 커넥션 풀, 배포 스크립트가 이
버전에서 모두 확립된다. 이후 모든 백엔드 기능(Auth, Calendar, Settings 등)이
이 스캐폴드 위에 구현된다.

## Major Changes

1. Fastify 앱 구조 확정 — `@fastify/autoload` 기반 plugin/route 자동 등록,
   `/v1` prefix.
2. `BaseGateway`/`BaseProvider` 어댑터 패턴 확립 — 이후 모든 외부 API
   연동(OpenWeather, Google Auth, Google Calendar)이 이 패턴을 따른다.
3. `AppError` + 전역 에러 핸들러로 ICD v0.0 공통 응답 envelope
   (`{success, data, error}`) 확정.
4. `request_logs`/`raw_logs` 로깅 체계, `pool.ts`(Postgres 커넥션 풀) 도입.

## Added

- `src/app.ts`, `src/config/{FastifyDefinition,env}.ts` — 앱 부트스트랩.
- `src/core/base/{BaseGateway,BaseProvider,BaseRoutes,BasePolicy}.ts` — 공통 베이스 클래스.
- `src/core/utils/{AppError,Crypto,Logger}.ts` — 에러 처리, 초기 암호화 유틸(스캐폴딩), 구조화 로깅.
- `src/db/pool.ts` — Postgres 커넥션 풀 싱글턴.
- `src/gateway/OpenWeatherAPI.ts` — 최초 concrete gateway(Weather 프록시).
- `src/plugins/LingOnConfig/ConfigHandler.ts`, `src/plugins/LingOnDataManage/{Policy,Repositories,RequestContext,RequestLog}.ts` — 플러그인 5종.
- `src/route/{LingOnStatus,LingOnWeather}.ts` — 최초 라우트 2개.
- `server_init.sh`, `server_deploy.sh` — 배포 스크립트.
